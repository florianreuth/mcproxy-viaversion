# mcproxy-viaversion

See https://github.com/ViaVersion/ViaVersion for the main project.

## To get started

- Download the latest jar from https://github.com/florianreuth/mcproxy-viaversion/actions and put it into your mc-proxy
  plugins folder
- Download ViaVersion from https://viaversion.com/ (and other addons if needed) and put them into the
  `plugins/ViaVersion/` folder
